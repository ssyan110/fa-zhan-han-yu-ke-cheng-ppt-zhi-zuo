# KN2／KN4 投影片製作

以根目錄 `製作契約.md` 為執行依據。這份 skill 只安排工作，不複製排版數值。

## 新課或尚未套版的課

1. 讀本課製作稿、教師確認紀錄與本課所屬 KN2／KN4 的 01 架構、02 頁型模板。來源有缺漏就列出確切缺漏，先完成不依賴它的部分。
2. 內容先完成：逐題列出題幹、作答位置、答案及課本來源；核對教師已確認範圍。不要用「已完成」文字代替核可紀錄。
3. 執行文件預檢。先修正重複頁碼、檔名與總數；不自動重新編號或刪除任何內容。
4. 找到本機實際產生器與本課建置命令，先核對模板版本。缺少產生器時可以繼續整理製作稿，不宣稱已產出投影片，也不重建一套新系統。
5. 先渲染本課最容易出問題的實際頁：長超綱例句、翻牌背面、最長對話練習、雙／三詞卡；每種使用到的新頁型至少一頁。內容已核可時，這是內部排版檢查，不是新增教師核可關卡。
6. 樣頁無溢出才批次套用同一模板；最後跑全課結構檢查與本課受影響頁型的互動檢查。
7. 交付本課輸出位置、測試版本、通過項目與未完成項目。圖片與 PDF 仍依已有核可範圍進行。

## 已有投影片的局部修正

1. 指明課次、頁面內容識別與問題；頁碼只用來定位，先確認沒有因拆頁而改號。
2. 內容錯誤改本課來源；重複排版錯誤改共用頁型；單頁特殊版面只改該頁設定。不得以全課樣式覆蓋解決單頁問題。
3. 只重建受影響頁；若增刪頁則更新整份導覽清單、頁碼與總數，保留課本來源。檢查相鄰頁及受共用模板影響的頁型。
4. 用相同畫布、字型與顯示狀態比較修改前後；記錄修正落在哪個來源檔。已解決的內容不重新設計。
5. 共用規格變更只維護 `製作契約.md`，KN2／KN4 特有教學差異仍放各自模板。未實際測試的舊 QA 勾選不能沿用。
