# KN4 課前預習 Formative 製作流程

用途：作為 `Kỹ năng nói 4` 每一課課前預習 Formative 作業的標準製作流程。  
定位：本文件是流程索引，不取代規則模板、題型模板、教師審核模板或上傳版模板。  
核心原則：先完成內容設計與教師審核，再整理成乾淨上傳版，最後依上傳版建立 Formative。

## 一、每課製作總流程

每一課依照以下順序製作：

1. 讀取總規則。
2. 讀取 Formative 題型結構。
3. 讀取課本與單字、語法資料庫。
4. 建立本課可用詞範圍。
5. 選重要句並設計題目。
6. 產出教師審核稿初稿。
7. 交付教師審核稿前，最後一次做生詞交叉比對。
8. 將生詞交叉比對結果寫入教師審核稿。
9. 交付教師審核稿給老師確認並修改。
10. 教師確認後，產出 Formative 上傳版。
11. 依上傳版建立 Formative。
12. 上傳音檔並完成 QA。

使用文件順序：

```text
課前預習、課中教學與回家作業規則.md
Formative題型結構模板.md
KN4課前預習教師審核模板.md
KN4課前預習Formative上傳版模板.md
```

## 二、製作前資料準備

每一課開始前，先準備以下資料：

- KN4 課本該課內容。
- 該課課名與課文標題。
- 每篇課文頁碼與段落位置。
- 每篇課文音檔。
- 該課課本生詞表。
- 該課「讀一讀，試一試」中的語法、句型或功能結構。
- 該課「詞語練習」中實際出現的生詞或練習詞。
- `單字、語法資料庫` 中 KN1、KN2、KN3 全部生詞，以及 KN4 已學課次生詞。

若音檔或課本頁面缺漏，先標記缺漏，不自行替代或猜測。

## 三、可用詞與超綱詞檢查

製作 KN4 某課時，可用詞範圍為：

- `Kỹ năng nói 1` 全部生詞
- `Kỹ năng nói 2` 全部生詞
- `Kỹ năng nói 3` 全部生詞
- `Kỹ năng nói 4` L1 至本課生詞

超綱詞處理規則：

- 原則上不得使用超綱詞。
- 若超綱詞來自課本題目原文、課本例句或課本指定句，視為課本輸入，忽略超綱限制，仍保留課本題。
- 上述例外只適用於課本原文；自編題目、改寫題、參考答案與學生必須產出的內容仍需避開超綱詞。
- 若不得已使用，必須標藍。
- 必須注記：漢字 / pinyin / 越南語。
- 不得放在答案中。
- 一句最多 1 個超綱詞。
- 一課最多 2 個超綱詞。

檢查位置：

- 題目文字
- 選項
- 參考答案
- 重要句
- 越南語翻譯中的中文詞
- Hint
- 生詞表

交付教師審核稿前的最後步驟：

- 必須再次以 `單字、語法資料庫` 做生詞交叉比對。
- 檢查重點為學生會看到、寫出或錄出的中文內容：題目、選項、參考答案、重要句、越南語翻譯中的中文詞、Hint、生詞表與學習困難回報題。
- 生詞表只可放該課課本生詞；不得自行加入課外詞。
- Phần 3 生詞表詞性欄位必須用英文簡寫，例如：`V.`、`N.`、`Adj.`；`非` 留空。
- 若超綱詞屬於課本題目原文、課本例句或課本指定句，於檢查結果註明「課本原文保留」，不因此刪改課本題。
- 若發現超綱詞，優先改用已學詞；不能替換時，必須標藍並注記漢字 / pinyin / 越南語，且不得放入答案。
- 比對完成後，必須更新教師審核稿的「超綱詞使用狀態」與「檢查結論」。
- 未完成此步驟，不得把教師審核稿交給老師確認。

## 四、教師審核稿製作流程

教師審核稿使用：

```text
KN4課前預習教師審核模板.md
```

教師審核稿目的：

- 讓老師檢查題目是否符合課本。
- 讓老師檢查重要句選句理由。
- 讓老師檢查生詞、語法、超綱詞與配分。
- 讓老師在正式上傳前修改內容。

教師審核稿需要保留：

- 基本資訊。
- 課本頁碼與課文位置。
- 每題題目。
- 每題參考答案。
- 重要句選句依據。
- Hint 內容。
- 生詞表。
- 超綱詞檢查。
- 音檔狀態。
- 配分理由。
- 教師審核清單。

教師審核稿不需要模仿 Formative 畫面排版，但必須讓老師一眼看出每題會放到哪個 Phần。

## 五、重要句選句流程

每篇課文選 2-3 題重要句聽讀。

選句順序：

1. 優先找「讀一讀，試一試」中對應的語法、句型或功能結構。
2. 再找「詞語練習」中實際出現的生詞或練習詞。
3. 若不足 2 題，才補課文中最有口語功能的句子。

每題重要句必須確認：

- 只放 1 個重要句。
- 題目卡顯示句子與音檔內容完全一致。
- 若縮短課本原句，必須同步重新裁切或重新生成對應短句音檔。
- 學生任務是聽完後錄音復述。
- 題型是 `Audio Response`。
- 必答。
- 不自動批改。
- 生詞紅色。
- 語法、功能句或句型紫色。
- 超綱詞藍色。
- Hint 中有完整說明。

Hint 規則：

- 生詞：漢字 / pinyin / 越南語。
- 語法：漢字結構 / pinyin / 越南語 / 使用情境說明（越南語）。
- 超綱詞：漢字 / pinyin / 越南語，並保留超綱標記。

## 六、題目生成流程

每篇課文固定包含以下 Phần。

### Phần 1：重要句聽讀

- 題數：2-3 題。
- 題型：Audio Response。
- 任務：聽重要句後錄音復述。
- 分數：低分。
- 音檔：每題音檔放在題目卡最前面。

### Phần 2：第一次聽課文

- 題數：1 題。
- 題型：Audio Response。
- 任務：不打開課本，只聽一次後回答大意。
- 分數：中分。
- 音檔：課文音檔放在題目卡最前面。
- 題目前綴：固定使用 `Câu hỏi:`，不寫 `听课文Ｘ以后，请说说：`。

固定指引：

```text
Nghe đoạn hội thoại một lần rồi trả lời câu hỏi (Không mở sách, chỉ nghe thôi). Hãy ghi âm trả lời câu hỏi.
```

### Phần 3：看課文後細節理解

- 題數：2-3 題。
- 題型：Audio Response。
- 任務：打開課本閱讀後回答細節。
- 分數：中高分。
- 音檔：不放音檔。

必須呈現：

- 課本頁碼。
- 課文標題。
- 段落位置。
- 該段落或文章生詞表。
- 生詞表詞性欄位統一使用英文簡寫，例如：`V.`、`N.`、`Adj.`；`非` 留空。

固定提醒：

```text
Formative không hiển thị toàn bộ "bài học". Hãy mở sách giáo khoa để đọc.
```

### Phần 4：第二次聽課文

- 類型：Text。
- 題目卡：無。
- 分數：0。
- 任務：再聽一次，對照課本。
- 音檔：放在 Text 區塊內。

固定提醒：

```text
Hãy nghe lại một lần nữa, đồng thời đối chiếu với đoạn trong sách. Hãy chú ý và cố gắng bắt chước giọng, ngữ điệu và các điểm ngắt nghỉ của nhân vật; đừng chỉ đọc qua một cách đơn giản.
```

### 學習困難回報

- 題數：整課最後 1 題。
- 題型：Short Answer 或 Long Answer。
- 分數：0。
- 必答：否。
- 自動批改：否。

固定題目：

```text
Bài học này bạn còn từ mới, câu hoặc nội dung nào chưa hiểu không? Nếu đã hiểu hết, bạn có thể để trống hoặc viết “Không có”.
```

## 七、Formative 上傳版製作流程

教師審核稿確認後，才製作 Formative 上傳版。

上傳版使用：

```text
KN4課前預習Formative上傳版模板.md
```

上傳版只保留：

- 作業標題。
- 學生須知。
- 課文標題。
- Phần Text 內容。
- 題型。
- 題目文字。
- 參考答案。
- Hint。
- 分數。
- 必答設定。
- 音檔位置。
- Submit 提醒。

上傳版刪除：

- 選題理由。
- 超綱詞審核表。
- 配分討論。
- 老師備註。
- 製作流程說明。

## 八、Formative 實際建置流程

建立 Formative 時依照上傳版逐項操作。

### 1. 作業開頭

1. 設定作業標題。
2. 在作業設定中關閉 `Display each item as a separate page`。
3. 新增學生須知 Text。
4. 確認 `Google Chrome` 紅色粗體。
5. 確認 `0 điểm` 紅色粗體。

### 2. 建立課文與 Phần

每篇課文依序建立：

1. 課文標題 Text，格式為 Heading 2。
2. Phần 1 Text，標題用一般文字、粗體、藍色，下方有黑色粗體 `Hướng dẫn:`。
3. 從 Phần 1 Text 右側 `+` 新增題目卡。
4. Phần 2 Text，標題用一般文字、粗體、藍色，下方有黑色粗體 `Hướng dẫn:`。
5. 從 Phần 2 Text 右側 `+` 新增題目卡。
6. Phần 3 Text，標題用一般文字、粗體、藍色，下方有黑色粗體 `Hướng dẫn:`。
7. 從 Phần 3 Text 右側 `+` 新增題目卡。
8. Phần 4 Text，標題用一般文字、粗體、藍色，下方有黑色粗體 `Hướng dẫn:`，不新增題目卡。

重要規則：

- 課文標題 Text 必須保留在每篇課文開頭，且必須是 Heading 2。
- Phần Text 內不可再次重複課文標題。
- 題目卡必須在 Phần Text 區塊右側新增。
- 不可新增在 Phần 區塊下方的外層位置。
- 若新增錯位置，必須刪除後重建。

### 3. 格式檢查

確認：

- 每個 Phần 標題為一般文字、粗體、藍色，不是 Heading 2。
- 每個 Phần 標題下方都有黑色粗體 `Hướng dẫn:`。
- 課文標題為 Heading 2。
- 課文標題沒有被誤刪，且沒有在 Phần Text 內重複出現。
- Phần 3 的 `P.{{page_range}}, 课文...` 為粗體。
- 生詞表標題 `汉字` 不紅。
- 生詞表漢字欄位內容紅色粗體。
- 生詞表詞性欄位為英文簡寫，例如：`V.`、`N.`、`Adj.`。
- 詞性為 `非` 時欄位留空。
- 重要句與越南語翻譯標色正確。
- Hint 內容完整。

### 4. 結尾

1. 在最後一個 Phần 下方新增學習困難回報題，不放在最後一個 Phần 的右側。
2. 設為非必答。
3. 設為 0 分。
4. 新增 Submit 提醒 Text。

Submit 提醒固定文字：

```md
<strong>Nhớ bấm nút <span style="color:red">Submit(Nộp bài)</span> sau khi hoàn thành bài tập.</strong>
```

## 九、音檔處理流程

音檔需依音檔對應表處理。

建議檔案：

```text
KỸ NĂNG NÓI 4-L{{lesson_number}}題型對應音檔表.md
KỸ NĂNG NÓI 4-L{{lesson_number}}題型對應音檔表.csv
L{{lesson_number}}題型對應音檔/
```

上傳位置：

- 重要句音檔：放在對應 Audio Response 題目卡最前面。
- 第一次聽課文音檔：放在大意題題目卡最前面。
- 第二次聽課文音檔：放在 Phần 4 Text 區塊內。
- Phần 3 細節理解題：不放音檔。

缺漏處理：

- 音檔缺漏時，不任意替代。
- 在教師審核稿標記缺漏。
- 在 Formative 上傳版標記缺漏。
- 實際上傳時跳過該音檔。

上傳後檢查：

- 每個應有音檔的題目都有音檔。
- 每題最多保留正確的 1 個音檔。
- 音檔沒有插在句子中間。
- 課文音檔沒有放錯課文。
- 重要句音檔播放內容與題目卡顯示句子完全一致。
- 若題目卡重要句曾縮短原文，已使用縮短後句子的音檔，而不是原文長句音檔。
- 課文二、課文三等後半課文也需逐題聽檢，不可只檢查課文一。
- 缺漏音檔沒有被相近檔案替代。

## 十、配分流程

若總分設定為 100 分，先依題型難度分配，不平均湊分。

配分原則：

- 重要句聽讀：低分。
- 第一次聽大意：中分。
- 一般細節理解：中高分。
- 因果、態度、推論題：高分。
- 學習困難回報：0 分。

配分檢查：

- 總分必須正確。
- 高分題必須有明確難度理由。
- 同類題型分數應一致，除非題目難度明顯不同。
- 學習困難回報不得計分。
- 非必答題不得承擔核心評量分數。

- [ ] 每個 Phần 是 Text 區塊。
- [ ] 每個 Phần 標題為一般文字、粗體、藍色，不是 Heading 2。
- [ ] 每個 Phần 標題下方有黑色粗體 `Hướng dẫn:`。
- [ ] 題目卡都在對應 Phần 右側。
- [ ] 沒有錯放在外層下方的題目卡。
- [ ] 課文標題為 Heading 2。
- [ ] 課文標題 Text 沒有被誤刪，且 Phần Text 內沒有重複課文標題。
- [ ] Phần 3 課文位置粗體。

- [ ] 第一次聽大意題目前綴為 `Câu hỏi:`，未使用 `听课文Ｘ以后，请说说：`。

## 十二、檔案保留與刪除規則

每課完成後建議保留：

- 教師審核稿。
- Formative 上傳版。
- 音檔對應表。
- 音檔資料夾。
- 必要的 PDF 或匯出檔。

可刪除：

- 臨時整理稿。
- 已被上傳版取代的草稿。
- 錯誤版本。
- 舊 Luna 版本。

不可刪除：

- 課本原始檔。
- 單字、語法資料庫。
- 本流程文件。
- 三份核心模板。
- 已確認仍會用於 Formative 的音檔。

## 十三、L2 製作錯誤吸收紀錄

本段記錄 `KỸ NĂNG NÓI 4-L2` 製作時已確認的錯誤，後續課次必須避免。

### 1. Phần 與課文標題格式

- 錯誤：把 Phần 標題做成 Heading 2。
- 正確：Phần 標題用一般文字、粗體、藍色；課文標題才用 Heading 2。
- 錯誤：刪除 Phần 上方獨立課文標題。
- 正確：每篇課文開頭保留獨立課文標題 Text；Phần Text 內不重複課文標題。
- 正確：每個 Phần 標題下方都要有黑色粗體 `Hướng dẫn:`。

### 2. 題目卡位置

- 錯誤：把應屬於 Phần 的題目卡新增在 Phần 下方外層位置。
- 正確：Phần 1、Phần 2、Phần 3 的題目卡，都必須從該 Phần Text 右側 `+` 新增。
- 例外：整課最後的學習困難回報題放在最後一個 Phần 下方，不放在最後一個 Phần 右側。

### 3. 音檔與重要句一致性

- 錯誤：課文二、課文三重要句音檔時間點或內容錯誤。
- 錯誤：題目卡顯示縮短句，但音檔仍播放原文長句。
- 正確：每題重要句音檔必須和題目卡顯示句子完全一致。
- 正確：若縮短原句，必須重新裁切或重新生成縮短後句子的音檔。
- 正確：課文一、課文二、課文三都要逐題聽檢，不可只抽查前段。
