# KN2 課前預習 Formative 製作流程

用途：作為 `Kỹ năng nói 2` 每一課課前預習 Formative 作業的標準製作流程。  
存放規則：本流程放在 `KN2 課前預習` 根目錄；每課教師審核稿、上傳版與音檔表放入本資料夾內的對應課次子資料夾。

## 一、每課製作總流程

每一課依照以下順序製作：

1. 讀取總規則：`課前預習、課中教學與回家作業規則.md`。
2. 讀取 Formative 題型結構：`Formative題型結構模板.md`。
3. 讀取 KN2 課本 PDF、KN2 單字資料庫與該課課堂 PPT 資料。
4. 建立本課可用詞範圍。
5. 選重要句並設計客觀理解題。
6. 產出教師審核稿初稿。
7. 交付教師審核稿前，最後一次做生詞交叉比對。
8. 將生詞交叉比對結果寫入教師審核稿。
9. 交付教師審核稿給老師確認並修改。
10. 教師確認後，產出 Formative 上傳版。
11. 整理與裁切音檔。
12. 開始操作 Formative 前，先確認 Google Chrome 設定檔名稱為 `Shihsiang Yan`；確認無誤後才可登入與操作，不得使用其他設定檔。
13. 依上傳版建立 Formative 並完成 QA。

每課子資料夾建議包含：

```text
KỸ NĂNG NÓI 2-L{{lesson_number}}課前預習教師審核稿.md
KỸ NĂNG NÓI 2-L{{lesson_number}}課前預習Formative上傳版.md
KỸ NĂNG NÓI 2-L{{lesson_number}}題型對應音檔表_v1待定位.md
L{{lesson_number}}課前預習音檔/
```

## 二、製作前資料準備

每一課開始前，先準備以下資料：

- KN2 課本該課內容。
- 該課課名與課文標題。
- 每篇課文頁碼與段落位置。
- 每篇課文音檔。
- 該課課本生詞表。
- 該課「大声读一读」中的語法、句型或功能結構。
- 該課「词语练习」或相關練習中實際出現的生詞。
- `單字、語法資料庫` 中 KN1 全部生詞，以及 KN2 已學課次生詞。

若音檔或課本頁面缺漏，先標記缺漏，不自行替代或猜測。

## 三、可用詞與超綱詞檢查

製作 KN2 某課時，可用詞範圍為：

- `Kỹ năng nói 1` 全部生詞
- `Kỹ năng nói 2` L1 至本課生詞

超綱詞處理規則：

- 原則上不得使用超綱詞。
- 若超綱詞來自課本題目原文、課本例句或課本指定句，視為課本輸入，忽略超綱限制，仍保留課本題。
- 上述例外只適用於課本原文；自編題目、改寫題、選項、參考答案與學生必須產出的內容仍需避開超綱詞。
- 若不得已使用，必須標藍。
- 必須注記：漢字 / pinyin / 越南語。
- 不得放在正確答案中。
- 一句最多 1 個超綱詞。
- 一課最多 2 個超綱詞。

交付教師審核稿前的最後步驟：

- 必須再次以 `單字、語法資料庫` 做生詞交叉比對。
- 檢查重點為學生會看到、選到、寫出或錄出的中文內容：題目、選項、參考答案、重要句、越南語翻譯中的中文詞、Hint、生詞表與學習困難回報題。
- 生詞表只可放該課課本生詞；不得自行加入課外詞。
- Phần 3 生詞表詞性欄位必須用英文簡寫，例如：`V.`、`N.`、`Adj.`；`非` 留空。
- 若超綱詞屬於課本題目原文、課本例句或課本指定句，於檢查結果註明「課本原文保留」，不因此刪改課本題。
- 未完成此步驟，不得把教師審核稿交給老師確認。

## 四、KN2 課前預習固定結構

每一課依課文數量分成 2-3 個課文單元。每個課文單元依序安排以下 Phần：

1. 重要句聽讀
2. 第一次聽課文
3. 看課文後細節理解
4. 第二次聽課文

整課最後加：

5. 學習困難回報

## 五、題型規則

### Phần 1：重要句聽讀

- 題數：每篇課文 2 題為主；必要時 3 題。
- 題型：Audio Response。
- 任務：聽重要句後錄音復述。
- 分數：低分。
- 音檔：每題音檔放在題目卡最前面。

選句順序：

1. 優先找「大声读一读」中對應的語法、句型或功能結構。
2. 再找「词语练习」或相關練習中實際出現的生詞。
3. 若不足 2 題，才補課文中最有口語功能的短句。

每題重要句必須確認：

- 只放 1 個重要句。
- 題目卡顯示句子與音檔內容完全一致。
- 若縮短課本原句，必須同步重新裁切或重新生成對應短句音檔。
- 生詞紅色。
- 語法、功能句或句型紫色。
- 超綱詞藍色。
- Hint 中有完整說明，且一個知識點一個 Formative hint 欄；多個生詞、語法或功能句不可合併在同一欄。

### Phần 2：第一次聽課文

- 題數：每篇課文 1 題。
- 題型：Multiple Choice。
- 選項：3 個選項。
- 選項格式：A/B/C 答案選項一律純文字，不加顏色、粗體、`<span>` 或其他 HTML 標記。
- Formative 設定：開啟「隨機順序 / 随机顺序」。
- 任務：不打開課本，只聽一次後選出大意答案。
- 分數：中分。
- 音檔：課文音檔放在題目卡最前面。
- 題目前綴：固定使用 `Câu hỏi:`，不寫 `听课文Ｘ以后，请说说：`。

固定指引：

```text
Nghe đoạn hội thoại một lần rồi chọn đáp án đúng <strong>(Không mở sách, chỉ nghe thôi).</strong>
```

題目方向：

- 誰跟誰說話？
- 他們在哪裡？
- 他們主要談什麼？
- 說話者想做什麼？
- 發生了什麼事？

### Phần 3：看課文後細節理解

- 題數：每篇課文固定 3 題。
- 題型：Multiple Choice。
- 選項：3 個選項。
- 選項格式：A/B/C 答案選項一律純文字，不加顏色、粗體、`<span>` 或其他 HTML 標記。
- Formative 設定：開啟「隨機順序 / 随机顺序」。
- 任務：打開課本閱讀指定課文位置後，選出正確答案。
- 分數：中高分。
- 音檔：不放音檔。

必須呈現：

- 課本頁碼。
- 課文標題。
- 段落位置。
- 該段落或文章生詞表。
- 生詞表詞性欄位統一使用英文簡寫，例如：`V.`、`N.`、`Adj.`；`非` 留空。

固定提醒：

```text
Formative không hiển thị toàn bộ "bài học". <strong>Hãy mở sách giáo khoa</strong> để đọc.
```

### Phần 4：第二次聽課文

- 類型：Text。
- 題目卡：無。
- 分數：0。
- 任務：再聽一次，對照課本。
- 音檔：放在 Text 區塊內。

固定提醒：

```text
Hãy nghe lại một lần nữa, đồng thời đối chiếu với đoạn trong sách. Hãy chú ý và cố gắng bắt chước giọng, ngữ điệu và các điểm ngắt nghỉ của nhân vật; đừng chỉ đọc qua một cách đơn giản.
```

### 學習困難回報

- 題數：整課最後 1 題。
- 題型：Free Response 或 Long Answer。
- 分數：0。
- 必答：否。
- 自動批改：否。

固定題目：

```text
Bài học này bạn còn từ mới, câu hoặc nội dung nào chưa hiểu không? Nếu đã hiểu hết, bạn có thể để trống hoặc viết “沒有”.
```

## 六、選項設計規則

KN2 的 Multiple Choice 題目必須降低閱讀負擔：

- 每題只放 3 個選項。
- 選項要短，不故意繞語法。
- 選項只使用純文字，不標色、不粗體、不加 HTML 標記；即使選項包含生詞或語法點，也不在答案選項中做標記。
- 正確答案避免使用超綱詞。
- 同一課的 Multiple Choice 正確答案位置必須分散，不得全部集中在 A、B 或 C。
- 連續 3 題 Multiple Choice 不得使用同一個正確答案位置。
- 每一張 Multiple Choice 題卡都必須在 Formative 設定中開啟「隨機順序 / 随机顺序」。
- 錯誤選項要合理，但不得使用超綱詞製造難度。
- 若選項中必須使用課本原文超綱詞，需在教師審核稿標記「課本原文保留」。
- 大意題不考細節記憶。
- 細節題不做過度推論。

## 七、配分規則

配分不可只平均分配，必須反映任務負荷。

建議 100 分配置：

- 重要句聽讀：每題 3-5 分。
- 第一次聽大意：每題 6-10 分。
- 看課文後細節理解：每題 7-10 分。
- 較難的因果、態度或推論題可略高。
- 學習困難回報：0 分，非必答。

## 八、Formative 實際建置提醒

建立 Formative 時依照上傳版逐項操作：

1. 開始操作 Formative 前，必須先確認 Google Chrome 設定檔名稱為 `Shihsiang Yan`；確認無誤後才可登入與操作，不得使用其他 Google 設定檔或其他老師帳號。
2. 設定作業標題。
3. 在 `Assign` → `Edit settings` → `Content display` 中關閉 `Display each item as a separate page`；可在未發布／未指派狀態下設定，不必先發布作業。
4. 填寫學生須知。
5. 每篇課文先建立課文標題 Text，格式為 Heading 2。
6. 建立 Phần Text，Phần 標題用一般文字、粗體、藍色。
7. 每個 Phần 標題下方都有黑色粗體 `Hướng dẫn:`。
8. 題目卡必須從所屬 Phần Text 右側／內部 `+` 新增，成為同一張 Text 卡右側欄位內的題目卡。
9. Phần 題型說明與 `Hướng dẫn:` 必須在 Phần Text 主文本內，不可另建右側獨立 Text 說明卡。
10. 不可把題目卡新增在 Phần 下方的最外層位置；畫面不得出現「文本在上、題目卡在下方獨立排列」。
11. 若題目卡已錯置在 Phần 下方，不可用拖曳／移動修復；必須先在正確 Phần Text 右側欄位重建新題卡，確認內容、分數、答案與音檔後，再刪除原本獨立題卡。
12. Hint 必須一個知識點一欄；若同題有 3 個提示知識點，就新增 3 個 hint 欄，不可合併在同一欄。
13. 所有 Multiple Choice 題卡都必須開啟「隨機順序 / 随机顺序」。
14. 第二次聽課文只建立 Text，不建立題目卡。
15. 音檔上傳後，必須刪除學生可見正文中的 `[Âm thanh: 檔名]`、音檔檔名或其他音檔佔位文字。
16. 上傳完成取得分享 link 後，必須先開啟 link 檢查 Formative 標題、課次與作業類型，確認這是對應課次的課前預習；若之後要提供給 PPT，也必須先確認擺放位置：本課課前預習 link 不放入同課課堂 PPT 收尾頁，只可作為上一課 PPT 的下一課預習入口。
17. 學習困難回報放在最後一個 Phần 下方，不放在最後一個 Phần 的右側。
18. 最後新增 Submit 提醒 Text。

QA 檢查：

- [ ] 課文標題 Text 未被刪除。
- [ ] `Display each item as a separate page` 已設為關閉；不需先發布作業即可設定。
- [ ] Phần Text 內未重複課文標題。
- [ ] 題目卡位於同一張 Phần Text 卡右側欄位內，不是文本下方獨立卡。
- [ ] 若曾發現錯置題卡，已採「先在 Text 內重建、再刪原獨立卡」處理，未用拖曳／移動修復。
- [ ] Hint 一個知識點一欄；未把多個生詞、語法或功能句合併在同一 hint 欄。
- [ ] Phần 2 與 Phần 3 使用 3 選項 Multiple Choice。
- [ ] Phần 3 每篇課文固定 3 題。
- [ ] Multiple Choice 正確答案位置已分散，未全部集中在同一選項。
- [ ] 所有 Multiple Choice 題卡已開啟「隨機順序 / 随机顺序」。
- [ ] Multiple Choice 的 A/B/C 答案選項為純文字，未標色、未粗體、未加 HTML 標記。
- [ ] 第一次聽大意題目前綴為 `Câu hỏi:`。
- [ ] Phần 3 生詞表漢字欄位紅色粗體，表頭不紅。
- [ ] Phần 3 生詞表詞性欄位為英文簡寫。
- [ ] 音檔位置正確。
- [ ] 音檔上傳後，學生可見正文中沒有 `[Âm thanh: 檔名]`、音檔檔名或其他音檔佔位文字。
- [ ] Formative 分享 link 已開啟檢查內容，確認標題、課次與作業類型正確；若要給 PPT 使用，也已確認應放位置。
- [ ] 重要句音檔與顯示文字完全一致。
- [ ] 總分為 100。
