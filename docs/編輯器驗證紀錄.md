# 編輯器驗證紀錄

2026-09-07，本倉庫新增 editor/，解決小幅位置、文字與圖片調整仍需反覆生成的問題。此紀錄分開說明功能測試與尚未完成的教材核對。

## 已實測

- Node 標準庫模型檢查：資料可往返、ID 穩定；拒絕重複 ID、不安全 ID、錯誤型別、無限座標、超出畫布、不支援物件及不安全圖片網址。
- Python 文件檢查器 8 項測試通過。
- 桌面 Chromium：拖曳、右下角縮放、雙擊直接改字、右側文字欄、復原／重做及重新整理保留修改。
- 圖片嵌入後重新整理仍存在；鎖定位置會停用座標欄位。
- 模擬最新修改超過保存容量，確認較早的存檔完成不會清除「尚未保存」提示。
- 同課程兩分頁同時編輯：舊分頁停止自動保存，重新整理確認新分頁內容未被蓋掉。
- 下載 JSON → 開啟 JSON 保留修改；最近課程可重新開啟。新增副本與上下移動投影片可復原／重做。
- 交付 ZIP 重新解壓後，在封鎖 HTTP／HTTPS 的 Chromium 中開啟、載入隨附 JSON 示範與翻牌均通過。
- 根目錄 index.html 以 file:// 直接開啟，修改名稱後重新整理仍保留；不用本機伺服器也可工作。
- 匯出單一 HTML 以 file:// 開啟，翻牌可切換；教師備註不輸出；含 script 標籤的文字不會執行。
- 放映視窗、全螢幕及翻牌互動通過。
- 五份現有 Markdown 分別匯入 50、57、60、60、67 頁，沒有因重複舊編號刪掉列。原文保存在教師備註。
- Chromium PDF：兩頁課程輸出兩頁 PDF，頁面 720 × 404.88 pt，沒有多出空白頁。

## 界線與剩餘工作

Markdown 匯入只擷取標記文字，沒有套用專用頁型、帶入所有圖片或自動分類題目與答案。KN4 L2／L3 的內容順序疑點仍需對照課本；保留所有列不代表解決教材疑點。既有製作稿中的 QA 勾選不作為本版驗證證據。

本版沒有 .pptx／任意 HTML 匯入、富文字拼音定位、手寫註記、雲端同步或多人協作。PDF 只有正面狀態。尚未驗證 Safari、Firefox、實體投影設備、所有實際教材正反面排版或完整課堂使用。未量測朋友備課時間，不能宣稱已從數天降至特定分鐘數。

## 後續修改的回歸檢查

執行 python3 -m unittest discover -s scripts -p 'test_*.py' 與 node scripts/test_editor_model.cjs。若修改編輯器，再於瀏覽器完成：拖曳文字 → 雙擊改字 → 復原／重做 → 加圖 → 等待已儲存 → 重新整理 → 下載課程檔 → 重開 → 匯出 HTML → 離線放映並點翻牌。修改存檔時另做兩分頁衝突；修改列印時核對 PDF 頁數。CI 僅執行程式／模型檢查，不冒充瀏覽器測試。
